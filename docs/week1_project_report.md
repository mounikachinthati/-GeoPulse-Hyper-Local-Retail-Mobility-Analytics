# GeoPulse – Week 1 Project Progress Report

## 1. Project Information

**Project Title:** GeoPulse – Hyper-Local Retail Mobility Analytics

**Domain:** Data Analytics and Geospatial Analytics

**Study Area:** Guntur, Andhra Pradesh

## 2. Project Objective

To analyze the geographic distribution of retail businesses and identify useful location-based business insights to support retail planning and decision-making.

## 3. Work Completed

### Day 1 – Project Setup
- Created the project folder structure.
- Prepared README and requirements files.
- Documented the problem statement.

### Day 2 – Dataset Collection and Cleaning
- Downloaded the Overture Maps Places dataset.
- Inspected and cleaned the dataset.
- Generated the processed retail locations CSV.
- Documented the data dictionary.

### Day 3 – Database Creation
- Created an SQLite database.
- Loaded 200 location records.
- Verified database records.

### Day 4 – SQL Analysis
- Developed SQL analysis queries.
- Analyzed retail categories and location records.
- Documented SQL findings.

### Day 5 – Exploratory Data Analysis
- Created retail distribution charts.
- Analyzed top retail categories.
- Visualized geographic coordinates.

### Day 6 – Geospatial Analysis
- Created an interactive Guntur retail map using Folium.
- Mapped 200 business locations.
- Distinguished retail and non-retail locations using markers.

### Day 7 – Business Insights
- Analyzed retail distribution.
- Identified leading retail categories.
- Prepared business insights and recommendations.

## 6. Key Findings

- Fashion and apparel is the largest identified retail category with 17 locations.
- Shopping has 10 locations.
- Restaurants have 7 locations.
- The interactive map displays the geographic distribution of all 200 locations.

## 7. Challenges and Limitations

- The dataset covers only a selected geographic area.
- Some locations have missing category information.
- Retail classification is rule-based.
- Actual customer footfall and sales data are not available.

## 8. Future Scope

- Integrate retail sales information.
- Perform geographic clustering.
- Develop a Streamlit dashboard.
- Build a FastAPI backend.
- Generate advanced location-based business recommendations.

During Week 1, the GeoPulse project progressed from initial setup and dataset preparation to SQL analysis, EDA, geospatial visualization and business insights.
